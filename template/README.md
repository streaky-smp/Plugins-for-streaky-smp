# PluginName

A Paper plugin for the Streaky SMP network.

## Requirements

- Paper 26.2+ (or compatible fork)
- Java 25

## Building

```powershell
pwsh ./build.ps1
```

The built JAR will be in `target/`.

## Installation

1. Build the plugin or download the latest release
2. Place the JAR in your server's `plugins/` directory
3. Restart the server

## Development

This plugin uses the shared CI templates from the [main repo](../README.md).
See [ServerCore](https://github.com/streaky-smp/ServerCore) for a full reference implementation.
